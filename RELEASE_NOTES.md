# Wol-rar 0.2.0

- Build native per Windows x64, Ubuntu x64 e macOS.
- Nuova scheda **Novità e aggiornamenti** con note locali e note della release più recente.
- Download diretto della nuova versione da GitHub, solo su richiesta, con verifica SHA-256 obbligatoria.
- Motori 7-Zip 26.05 ufficiali inclusi per ciascuna piattaforma.
- Supporto alla firma Authenticode Windows e alla firma/notarization macOS tramite certificati configurati.
- Nessuna telemetria, account o connessione automatica.

La creazione di archivi RAR resta esclusa; RAR è supportato soltanto in lettura tramite 7-Zip.
